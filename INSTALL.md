WiFiManagerCustom - Installation & Examples

Zip package: `WiFiManagerCustom-1.0.0.zip` is included in the project root and can be installed via Arduino IDE (Sketch > Include Library > Add .ZIP Library...).

Examples:
- `examples/WiFiManagerTest/WiFiManagerTest.ino` - Basic usage
- `examples/WiFiManagerOTA/WiFiManagerOTA.ino` - OTA integration example (requires ArduinoOTA)
- `examples/WiFiManagerSecure/WiFiManagerSecure.ino` - Secure portal example (AP password)

PlatformIO:
- `platformio.ini` is included for quick build with the `esp32-c3-devkitm-1` environment.
